# Issue Tracker

Issues for this repository are tracked in Linear.

## Workflow

- Read and manage issues using the `linear` MCP tools (e.g. `list_issues`, `get_issue`, `save_issue`).
- When opening a new task or issue, ALWAYS ensure it is related to the relevant Linear project. If you don't know the project or it doesn't exist, ask the user before creating.
- Whenever you mention or display a Linear issue ID, format it as a clickable markdown link (e.g., `[JUS-283](https://linear.app/justaiit/issue/JUS-283)`).
